Политика конфиденциальности

Приложение «Life System» — личный инструмент одного пользователя (автора проекта) для персональной аналитики продуктивности и здоровья.

Как используются данные: через официальные API (Google Fit, OneDrive, FatSecret и др.) система читает данные только самого владельца проекта — шаги, сон, пульс, питание, экранное время — и формирует для него персональные отчёты.

Данные не продаются, не передаются третьим лицам и не используются для рекламы. Обработка происходит на личном сервере владельца.
